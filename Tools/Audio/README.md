# FreshGuard 音效

当前共 31 个音效：28 个由 `build_sfx.py` 原创合成；普通与彩色玻璃破碎使用用户调整后的「玻璃破碎.MP3」；机器人碰撞使用用户提供的「刀打骷髅.MP3」。重新生成时只写入实际发生变化的 WAV。

生成环境需要 Python 3 与 NumPy。运行 `python Tools/Audio/build_sfx.py` 可按固定随机种子和保存的用户素材母版，重新生成相同的 WAV 及对应配置。

- 音频：`Assets/AssetRaw/Audios/FreshGuardSfx/fg_*.wav`，44.1 kHz、单声道、16 bit PCM。
- 配置：同目录 `FreshGuardSoundCatalog.json`，记录事件、音量、播放间隔、循环和触发说明。
- 加载：沿用 Audios 的 YooAsset 文件名寻址；GameApp 启动时异步预热，关闭时释放本套资源。
- 播放：通过 TEngine 音效与界面音轨，沿用项目已有总音量、分类音量和开关。
- 修改听感：可替换同名 WAV，或调整配置的 `volume` 和 `cooldown`。重新运行生成器会覆盖生成的 WAV 与配置，长期调整需同步修改生成器中的参数。
- 滚轴为唯一循环音，随最后一个槽位停定或界面取消而停止。棋盘音效仅播放己方撞墙、玻璃受击与破碎、机器人碰撞、塔受伤与摧毁；敌方棋盘不播放音效，也不占用己方播放间隔。通用界面、开战、波次与胜负结算提示保留。
- 玻璃受击保留原版音色和 40% 音量。普通与彩色玻璃破碎使用用户提供的 `F:/视频剪辑/玻璃破碎.MP3`，完整时长约 0.183 秒，不叠加和弦。素材本身音量和采样内容在格式转换后保持原样，游戏内基础音量仍为 60% / 69%。
- 当前玻璃原文件、解码母版及来源记录在 `Tools/Audio/Sources/GlassBreak_User/`。此前 OpenGameArt CC0 素材与许可保留在 `GlassBreak_CC0/`，仅用于历史追溯；重新生成无需联网。
- 机器人碰撞使用「刀打骷髅.MP3」，音量 46%，最短间隔 0.09 秒。普通与暴走首次接触、放置重叠接触、脱困端点反弹均可触发；暴走持续接触的攻击脉冲不重复播放。
- 用户原 MP3 存在 `Tools/Audio/Sources/刀打骷髅.MP3`，解码母版为同目录 `robot_hit_user.wav`；游戏实际使用 `fg_robot_hit.wav`。原文件来自 `D:/WXWork/1688857841762135/Cache/Zip/转刀音效/音效/刀打骷髅.MP3`，仅做单声道 PCM 转码、峰值匹配与首尾淡化，保留原音高和时长。
- 敌人本体与机器人攻击、技能、死亡声音，以及背景音乐、环境循环、低血量预警未加入。BUFF 选择提示已连接现有界面，该界面仍由原流程决定何时打开。

Excel 对应表由同一份生成后的配置导出。表内的音量为单条声音的相对音量，最终还受项目现有混音音量影响。

## 首版及己方棋盘调整验证

- Unity 2021.3.50f1 编译通过。
- 音效资源、商店规则、玻璃、塔、结算和匹配的 128 项 EditMode 检查通过。
- 当前场景验证：30 个音效均进入框架音频池；匹配、倒计时、开战、玻璃、收币、波次、暴走、塔扣血、胜负、领取奖励和神秘商店的声音触发正常。
- 滚轴循环在转动期间实际播放，最后停槽后停止，没有重新启动或残留循环。
- 同帧重复调用受播放间隔限制；声道复用后旧滚轴句柄不能停止新声音；播放音效不消耗 Unity 玩法随机序列。
- 己方棋盘调整验证：撞墙、玻璃受击、普通与彩色玻璃破碎、塔受伤与摧毁的六类敌方事件全部静音；紧随其后的己方事件正常播放。界面点击、开战与胜负提示正常。
