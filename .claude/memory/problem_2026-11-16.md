# 2026-11-16：Unity 测试筛选参数

- 问题现象：按参考文档传入 `run_tests.params.filter` 时，当前 Unity MCP 忽略该字段并启动全量测试。
- 文档位置：`.claude/skills/tengine-dev/references/mcp-tools.md` 的“run_tests / get_test_job：自动化测试”小节。
- 正确 API：`Packages/com.coplaydev.unity-mcp/Editor/Tools/RunTests.cs` 的 `GetFilterOptions` 读取 `testNames`、`groupNames`、`categoryNames`、`assemblyNames` 数组；例如 `{"mode":"EditMode","testNames":["GameLogic.Tests.RobotSkillConfigTests"]}`。
- 建议修正：将示例中的 `filter` 改为 `testNames` 数组，并在首次轮询时核对总用例数和当前用例是否落在预期范围。
